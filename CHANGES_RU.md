# VPN Optimizer v2.5.1 — состав выпуска

Релиз v2.5.1 — первая версия проекта для самостоятельной установки. Программа дополняет существующие AWG Manager и sing-box, а не устанавливает VPN-систему вместо них.

## Основные возможности

- Ночная проверка подписки, измерение задержки и реальной скорости передачи данных, выбор подходящего сервера.
- Контроль работоспособности текущего VPN через HTTPS и периодические проверки скорости.
- Поиск альтернативного сервера при сбоях; сохранены проверки доступности и механизм восстановления маршрутизации.
- Telegram-бот: просмотр результатов, управление проверками и переключением, уведомления.
- Повторная отправка ночного Telegram-отчёта после временного сбоя соединения.
- Настройка ночного времени и часового пояса через отдельный конфигурационный файл.
- Совместимость с Entware cron, включая Vixie cron; учтён ограниченный PATH задания cron.
- Обработка дополнительных служебных полей AWG Manager в ответе rule-set без ослабления проверки состава доменных правил.

## Дистрибутив

Исполняемые shell-скрипты, Python-модуль общих проверок, Telegram-бот, init-скрипты Entware, проверка окружения `tools/preflight.py` и шаблон конфигурации. Рабочие токены, ключи подписки и личные настройки в комплект не входят.

Документация: `README_RU.md`, `README_EN.md`, `INSTALL_RU.md`, `INSTALL_EN.md`, `AI_INSTALL_PROMPT_RU.md`, `AI_INSTALL_PROMPT_EN.md`, `SECURITY_AUDIT_RU.md`; `TEST_RESULTS.txt` описывает тесты и их ограничения. Контрольные суммы файлов перечислены в `SHA256SUMS`.

## Испытания и ограничения

В реальной эксплуатации подтверждены запуск через cron, выбор сервера, восстановление TPROXY и отправка Telegram-отчёта. Повтор уведомлений после временного сбоя проверен имитационным тестом. Список гарантированно совместимых моделей и комбинаций версий не определён: необходима проверка предварительных требований и работающего VPN.

Полный повторный прогон автоматизированных тестов на окончательной редакции комплекта не подтверждён; подробности приведены в `TEST_RESULTS.txt`.
